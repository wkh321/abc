====================================================================
函数绘制器 AI 终端指令参考（完整版）
====================================================================
【识别标识】
所有指令必须包裹在 ```command ... ``` 代码块中，否则不会被解析执行。
AI 可在普通文本中穿插代码块，并在每个代码块写完后，添加“;”系统只提取代码块内的指令并顺序执行。
【指令格式】
指令名 参数1 参数2 ...
- 指令名不区分大小写
- 参数之间用空格分隔
- 颜色值使用十六进制，如 #RRGGBB
- 项目 ID 格式见下方说明

====================================================================
一、视图控制指令
====================================================================

set unit <数值>
  设置数轴单位长度（每个大格代表的数值）
  例: set unit 2

set grid <数值>
  设置网格密度（像素/单位长度）
  例: set grid 5

set minor <整数>
  设置每个大格内的小网格细分数（2~10）
  例: set minor 4

set pointsize <数值>
  设置坐标点显示的半径大小（1~20）
  例: set pointsize 6

set precision <数值>
  设置函数曲线采样步长（0.001~0.1，越小越精细）
  例: set precision 0.005

set decimals <整数>
  设置坐标轴标签和坐标值显示的小数位数（0~13）
  例: set decimals 3

set majorcolor <#颜色>
  设置主网格线颜色
  例: set majorcolor #ff0000

set minorcolor <#颜色>
  设置细分网格线颜色
  例: set minorcolor #00ff00

show grid on|off
  显示/隐藏主网格
  例: show grid off

show minor on|off
  显示/隐藏小网格
  例: show minor on

show xaxis on|off
  显示/隐藏 X 轴
  例: show xaxis off

show yaxis on|off
  显示/隐藏 Y 轴
  例: show yaxis on

reset view
  重置视图到默认状态

====================================================================
二、项目管理指令
====================================================================

add function <表达式>
  添加函数曲线（支持显式 y=f(x) 或隐式方程）
  支持运算符 + - * / ^ 和括号，数学函数见后
  例: add function y=sin(x)
      add function x^2 + y^2 = 1

add point <x> <y> [标签]
  添加坐标点，标签为单个大写字母（可选，自动分配）
  例: add point 2 3
      add point 0 0 O

add param <名称> <min> <max> <step> <初始值>
  添加可调参数（滑动条），名称为小写字母
  例: add param a -5 5 0.1 1

add segment <点A标签> <点B标签>
  添加线段，连接两个已存在的坐标点（标签为大写字母）
  例: add segment A B

add line <点A标签> <点B标签>
  添加无限直线，经过两个点
  例: add line A B

add ray <点A标签> <点B标签>
  添加射线，从点A出发经过点B无限延伸
  例: add ray A B

delete <项目ID>
  删除指定项目（自动处理依赖关系）
  例: delete fx_1

hide <项目ID>
  隐藏项目（仍在列表，画布不显示）
  例: hide xy_1

showitem <项目ID>
  显示已隐藏的项目
  例: showitem xy_1

setcolor <项目ID> <#颜色>
  更改项目颜色
  例: setcolor fx_1 #00aaff

setlabel <项目ID> <新标签>
  更改坐标点或连线的显示标签（单个字母）
  例: setlabel xy_1 C

clear all
  清空所有项目（无确认，谨慎使用）

====================================================================
三、项目 ID 格式说明
====================================================================

函数:   fx_1, fx_2, ...
坐标点: xy_1, xy_2, ...
参数:   pa_1, pa_2, ...
线段:   line_1, line_2, ...
直线:   line2_1, line2_2, ...
射线:   line3_1, line3_2, ...

可在项目列表中展开卡片查看具体 ID。

====================================================================
四、支持的运算符和数学函数
====================================================================

运算符:  + - * / ^ ( )
数学函数:
  sin, cos, tan
  asin, acos, atan
  log, ln
  sqrt, abs, exp
  以及 mathjs 库支持的其他函数（如 nthRoot, floor, ceil 等）

====================================================================
五、执行规则与注意事项
====================================================================

1. 指令按代码块内的行顺序依次执行。
2. 每条指令独立，失败不影响后续指令（会在工具卡片显示错误）。
3. 执行修改项目的指令前，系统自动保存一份快照，支持通过“回退”按钮恢复。
4. 免费 AI 模型（DeepSeek-V4-Pro）不支持流式输出，但可通过“数据同步”按钮更新项目上下文。
5. 付费模型支持流式输出和 Markdown 格式，需在设置中配置 API Key。
6. 坐标点标签必须唯一；连线标签自动生成小写字母。
7. 若指令执行成功，工具卡片显示“✅ 执行成功”及反馈信息；失败则显示“❌ 执行失败”及错误原因。
